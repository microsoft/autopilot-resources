# Autopilot Resources

Resources for administrators and users of Autopilot in Microsoft Copilot, plus administrator resources for Scout Desktop.

## Autopilot

- [Export an Autopilot workspace](workspace-export/README.md): download a private copy of an Autopilot workspace, including memories and sessions, to a Windows PC. Users can export their own workspace, and tenant administrators can export a user's workspace for a compliance or privacy request. [Download the tool](workspace-export/Autopilot-Workspace-Export.zip).

## Scout Desktop

Policy files for managing Scout Desktop:

- Windows Group Policy: [microsoft-scout.admx](admins/microsoft-scout.admx) with [en-US/microsoft-scout.adml](admins/en-US/microsoft-scout.adml)
- macOS configuration profile: [microsoft-scout.mobileconfig](admins/microsoft-scout.mobileconfig)
