
# Support

## If you need support for using Scout

You can get support for Scout through the same channels you use for other Microsoft 365 support issues: through the Support tools in the [Microsoft 365 admin center](https://admin.cloud.microsoft/#/) or by posting on the [Microsoft 365 Copilot](https://techcommunity.microsoft.com/category/microsoft365copilot/discussions/microsoft365copilot) forum at the Microsoft Tech Community.

## How to file documentation issues and get help  

This documentation project uses GitHub Issues to track bugs and feature requests. Please search the existing 
issues before filing new issues to avoid duplicates.  For new issues, file your bug or 
feature request as a new Issue.

## Microsoft Support Policy  

Support for this **PROJECT or PRODUCT** is limited to the resources listed above.
